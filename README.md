# 📖 Overview

The **Introduce Yourself** program is a beginner-friendly C++ console application that presents a personal profile in a clean and organized format. It demonstrates the use of functions, variables, conditional statements, and formatted output.

---

# ✨ Features

✅ Displays a personal profile

✅ Shows pet preference (Dog or Cat)

✅ Uses a separate function for displaying information

✅ Clean and organized console output

✅ Beginner-friendly C++ project

# 📝 Information Displayed

The program displays the following details:

- 👤 Name
- 🎂 Birthday
- 📍 Address
- 🎵 Favorite Song

# 🚀 Getting Started

```bash
g++ mee.cpp -o introduce
```

---

## ▶️ Run

### Windows

```bash
introduce.exe
```

### Linux / macOS

```bash
./introduce
```
