# 💖 Algorithm

## 📖 Overview

A simple JavaScript program that determines whether someone is worth approaching based on three conditions:

- Good-looking
- Kind
- Smart

If all conditions are met, the program prints a positive message.

---

## ✨ Features

- Uses Boolean variables
- Demonstrates conditional statements
- Simple decision-making logic

# 🚀 Getting Started

## Requirements

- Node.js (v16 or later recommended)
- Visual Studio Code (Recommended)

---

## ▶️ Run a Program

Navigate to the project folder and run:

```bash
node filename.js
```

Example:

```bash
cd FloodSafeDeliveries_07-17-26
node SafeDeliveries.js
```

or

```bash
cd Algorithm_07-21-26
node algo.js
```
